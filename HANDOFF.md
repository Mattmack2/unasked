# Handoff — Unasked v2

## Current state

Unasked v2 is live in `Mattmack2/unasked` as a lightweight personal horizon scanner / research field journal.

The current system has:

- a Question–Consequence discovery unit;
- six acquisition lanes including weak signals, expectation violations, and MEMORY-BLIND;
- rolling domain-diversity pressure;
- a durable candidate archive for stepping stones/dead ends;
- evidence and discovery-status labels;
- mandatory simple / interesting / tangible entry sections;
- a paper/editorial GitHub Pages reader;
- a research-first/local-edit prose policy in `VOICE_AND_AUTHORSHIP.md`;
- strict reservation of `NEW DISCOVERY` for externally validated original findings.

One earlier item is published in `docs/feed.json`. A MEMORY-BLIND Turn 1 on deep-time palaeoproteomics is frozen at `research/full/2026-08-21-palaeoproteomics-deep-time-turn1.md` and intentionally **not published yet**. The next research invocation must perform Turn 2 on that frozen report before beginning the next Turn 1.

## Deployment

Repository persistence is active. GitHub Pages still needs the repository setting **Deploy from a branch → `main` → `/docs`** if it has not already been enabled.

## First live test

Run several manual cycles before changing the architecture. Review:

- domain spread;
- proportion of MEMORY-BLIND / far-bridge items;
- repeated vocabulary neighborhoods;
- Turn 2 retirement/correction rate;
- whether the simple/interesting/tangible modules actually make dense subjects enjoyable;
- whether articles produce reusable mental-model changes rather than merely trivia;
- whether the article corpus starts sounding like the same LLM essay with different nouns.

After roughly 8–12 manual articles, perform the cross-article prose audit described in `VOICE_AND_AUTHORSHIP.md` rather than adding generic anti-AI rules piecemeal.

Do not add infrastructure because the interface looks finished. The content loop is still the product hypothesis.
