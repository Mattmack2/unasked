# Handoff — Unasked v2

## Current state

Unasked v2 is a lightweight personal horizon scanner / research field journal.

The v2 changes broaden the project beyond a tech-heavy personalized feed:

- explicit Question–Consequence discovery unit;
- six acquisition lanes including weak signals and expectation violations;
- rolling domain-diversity pressure;
- durable candidate archive for stepping stones/dead ends;
- evidence and discovery-status labels;
- mandatory simple / interesting / tangible entry sections;
- an archival paper/editorial reader UI;
- strict reservation of `NEW DISCOVERY` for externally validated original findings.

One earlier item is published in the bundled feed. A new MEMORY-BLIND Turn 1 on deep-time palaeoproteomics is frozen and intentionally **not published yet**; it must receive Turn 2 in a later invocation.

## External blocker

The connected GitHub capability can write to an existing repository but does not expose repository creation. The user is creating an empty repository named `Mattmack2/unasked`.

Until it exists, do not write Unasked material into another repository.

## When the repository exists

Populate the empty repository from this project, preserve the current files and Git history where practical, then enable Pages from `main` → `/docs`.

## First live test

Run several hourly cycles before changing the architecture. Review:

- domain spread;
- proportion of MEMORY-BLIND / far-bridge items;
- repeated vocabulary neighborhoods;
- Turn 2 retirement/correction rate;
- whether the simple/interesting/tangible modules actually make dense subjects enjoyable;
- whether articles produce reusable mental-model changes rather than merely trivia.

Do not add infrastructure because the interface looks finished. The content loop is still the product hypothesis.
